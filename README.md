# WT Tactical Overlay

战争雷霆原生小地图战术参考浮层，使用 Windows WPF 和 .NET Framework。自动匹配地图底图、读取本机网格信息，将内置的社区点位、危险区域和机动路线叠加到小地图上。

当前版本 **v0.4.1**。这是固定地图资料参考，显示内容不代表实时敌情。

## 下载和使用

1. 从 [Releases](https://github.com/Tyraelone/wt-tactical-overlay/releases/latest) 下载 Windows x64 压缩包并解压。
2. 退出旧版浮层，再运行 `Start-Overlay.cmd`。建议游戏使用无边框窗口模式。
3. 首次使用时，指向小地图实际内容左上角按 `Ctrl+Alt+1`，再指向右下角按 `Ctrl+Alt+2`，保存屏幕位置。这一步只框选地图边缘，不需要添加战术点。
4. 保持“自动识别地图（8111）”开启，点击启用。地图识别与坐标就绪后显示；尚未就绪时自动等待并隐藏标记。

通用安装包不含任何个人校准或个人笔记。位置、大小或显示器布局变化后需重新框选。

| 快捷键 | 功能 |
|---|---|
| Ctrl+Alt+F8 | 启用 / 停用浮层 |
| Ctrl+Alt+F9 | 鼠标穿透 / 交互说明 |
| Ctrl+Alt+F10 | 显示 / 隐藏控制台 |
| Ctrl+Alt+F11 | 退出 |
| Ctrl+Alt+1 / 2 | 捕获小地图左上角 / 右下角 |

## 内置资料

- 68 套有资料的参考布局，均包含远射点和风险提示；其中包括同一地图不同底图或版本。
- 2,422 个战术位置，含 587 个狙击 / 远射标记；1,165 条路线。
- 1,941 条危险提示，其中 158 块为危险区域轮廓。

数字按地图方案、模式和资料视角计数，可能重复同一地理位置，不代表独立实测位置数。危险区域和条件性风险默认开启，无需手动补点。详见 [覆盖清单](COVERAGE.zh-CN.md)。

| 显示 | 含义 |
|---|---|
| 红色半透明区域 | 来源绘出的危险或不建议进入区域 |
| 红色虚线带 | 来源明确标为危险的通路，带宽不表示火力范围 |
| 红色三角警告 | 风险位置，短线指向点位，无射程半径含义 |
| 黄点 / 蓝点 / 绿点 | 远射 / 观察架线 / 卖头参考点 |
| 绿线 / 黄线 / 橙线 | 掩护 / 侧翼 / 直接进攻路线 |
| 紫点或紫线 | 普通战术点或未明确分类的机动路线 |

交互模式下悬浮查看说明、适用条件和来源，也可使用控制台列表。红 / 蓝指资料的出生视角，不是实时敌我。底图不能总是区分本局三点、单点或战斗模式；默认资料方案会明确显示，可在控制台筛选已有方案。

## 自动识别与对齐

程序只读取本机 `http://127.0.0.1:8111/map.img` 和 `map_info.json`。不读取单位坐标、游戏进程内存，不注入、不拦截渲染，也不操作车辆。缺少有效地图、定位不可靠或连接中断时隐藏浮层并重试。

原生网格与资料图子图位置共同决定当前视野，已验证的屏幕矩形在相同显示器布局下复用。识别使用68张参考图的数值颜色特征；未知或歧义候选会被拒绝。相关性分数不是识别正确率。

v0.4.1 修复识别未就绪时的“缺少原生网格或资料图定位”弹窗：屏幕位置可先保存，启用请求保持待命并可取消，识别就绪后再显示；不以默认满图范围代替缺失的真实定位。

个人数据保存在程序目录的 `user-data/annotations.json`，保存时备份 `.bak`。配置损坏时保留原文件并禁止覆盖。

## 构建与测试

需要 Windows 10/11 x64、.NET Framework 4.8 和 PowerShell 7。使用系统自带的 .NET Framework C# 编译器，无需额外 SDK、Python 或运行时下载。

```powershell
pwsh -File ./build.ps1
pwsh -File ./test.ps1
pwsh -File ./package.ps1
```

产物在 `bin/`，通用压缩包在 `dist/`。构建不会改写游戏目录。源码版首次运行前需先构建。

57 项回归测试覆盖坐标投影、校准证明、待命保存、风险轮廓及孔洞、资料完整性、配置兼容和识别策略。验证范围和限制见 [验证说明](docs/VALIDATION.md)。

## 资料与限制

来源包括 [RATLINE](https://ratline.site/guides/)、[WarDevOps](https://wardevops.github.io/) 和公开地图目录。逐条来源与适用条件保存在数值地图库中。第三方原始地图图片、截图、长文、网站代码、研究缓存和构建时图像处理依赖不随仓库或安装包分发；参考图片只在明确请求预览时临时加载。详情见 [第三方来源说明](THIRD-PARTY-NOTICES.md)。

范围为陆战固定参考资料。当前仍有历史关卡身份 / 几何缺口，全部模式、裁切和当前版本逐点实战验证尚未完成；冬季及核爆原点明确标为地形配准参考。混合 DPI 多屏、独占全屏、未反映到8111的手动缩放尚未完整验证。

This is an unofficial, Windows-only static tactical-reference overlay for War Thunder. It does not show hidden enemies or provide live enemy intelligence. Source attribution and condition labels are retained; the project is not affiliated with Gaijin.
