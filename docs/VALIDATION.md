# 验证范围

v0.5.1 的完整回归共70项。

| 测试 | 数量 |
|---|---:|
| 核心坐标、配置、持久化与识别授权 | 20 |
| 原生网格与子图坐标换算 | 8 |
| 风险过滤、孔洞、命中和几何校验 | 7 |
| 实际资料来源、上下文和兼容性 | 5 |
| 无窗口 WPF 校准、待命及副屏地图流程 | 16 |
| 图像识别与歧义策略 | 14 |

测试入口为 `test.ps1`，结果写入被Git忽略的 `test-results.json`。测试使用临时目录，不操作游戏界面。

副屏用例验证了无屏幕校准时的矩形底图等比显示、裁切边界的点位换算，以及换图和断线时清除旧图层。主屏校准写入失败时，副屏可继续显示已定位的地图。

新增用例覆盖新旧识别格式、同一地图多个模板、局部参考向完整坐标系的换算，以及多个同地形候选对歧义比较的影响。识别阈值保持为相关性至少0.94、比其他地形家族至少高0.055。

开发阶段另对154张底图进行离线检查：81张当前来源模式底图、70张历史或当前参考图、3张已保存的只读API底图。154张均匹配到对应地形家族，153个名称完全一致；东欧与欧洲省共享地形。81套当前来源模式全部通过。移除正确家族后的154次检查均拒绝其他地形，参考坐标最大投影偏差为底图边长的0.28125%。这些结果不等于所有当前客户端任务的识别正确率。原始参考图不在仓库中，因此标准测试不重复依赖这些图的审计。

自动识别曾通过只读本地API捕获验证，原生网格换算也经过离线几何核对。缺少网格或资料定位时，底层投影继续拒绝计算；上层保存屏幕位置及等待启用不再触发该异常。

资料按社区来源或明确标记的地形配准提供。没有完成所有位置、车辆条件、地图变体与当前游戏版本的实战检查。未使用自动化控制游戏、进入匹配或操作车辆进行验收。运行时叠加效果与显示器适配仍需使用者确认。
